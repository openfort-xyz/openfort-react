Dropped React 17 and Node.js versions before 20 from the supported runtime range. React 18.3.1 or newer is required, while React, React DOM, TanStack Query, and viem are bounded below their next major versions. Updated the animation runtime and its call sites for React 19's component, ref, transition, and exit-ordering types, and updated the core browser SDK to a release whose HTTP dependency accepts patched Axios versions.
